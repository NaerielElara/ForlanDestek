# Forlan Destek 1.17.0 doğrulama

## Kapsam

Windows Forlan istemcisi için tek seferlik temiz başlangıç ve portable/kurulu güncelleme geçişi. Sunucu veritabanı, Docker projeleri, sunucu anahtarları ve diğer uygulamalar sıfırlama kapsamına girmez.

Mevcut Windows bağımlılığına Cryptography API özelliği açıldı; yeni bağımlılık eklenmedi. `deploy/forlan-support/tests/test_management.py` içine iki oturum geri yükleme/iptal regresyon testi eklendi.

Forlan dışındaki istemcilerin eski native güncelleme yolu ve Windows dışındaki native sıfırlama/güncelleme yolları korunur. Paylaşılan trait/struct/FFI imzaları, protokol ve alt modüller değiştirilmedi. Yeni bağımlılık veya bağımlılık sürüm yükseltmesi yapılmadı. Son farklar ana ve ek arayüz başlangıç kopyalarıyla incelendi; gereksiz düzenleme yapılmadı. Bu teslimat Windows x64 içindir; başka platform paketi oluşturulmadı.

## Sıfırlama güvenliği

- Yalnız `ForlanDestek` ve `Forlan Destek` profilleri ile Forlan paket önbelleği hedeflenir.
- Genel Temp silinmez. Sürümü açıkça adında bulunan eski Forlan paketleri ve tanımlanmış Forlan geçici dosyaları temizlenir.
- Tamamlanma işareti silinen profil dışında tutulur. Yeni veriler sonraki açılışlarda korunur.
- `--version` ve `--build-date` kişisel profili sıfırlamaz. İlk güncelleme ve kurulu bakım çağrısı eski süreçler kapatıldıktan sonra, yeniden açmadan önce sıfırlamayı güncelleyicinin kendi Windows dosya bağlamında tamamlar. Normal ilk açılış da aynı tamamlanma işaretini kontrol eder.
- Mutlak yol, dizin dışına çıkış, junction ve symlink kontrolleri korunur.
- Windows dosya yönlendirmesi varsa yalnız aynı Forlan klasörünün doğrulanmış fiziksel `LocalCache/Local` veya `LocalCache/Roaming` karşılığı önce temizlenir. Başka paket verileri taranmaz veya silinmez.
- Kurulu güncelleyicinin yeniden açma süreci korunur; portable güncelleme sabit launcher ve masaüstü kısayolu oluşturur.

## Giriş kalıcılığı

- Kayıt Windows kullanıcısına bağlı DPAPI ile şifrelenir; parola veya lisans kodu kaydedilmez.
- Access token 12 saat, yenilenebilir kayıt 30 gündür. Açılış/yenileme sunucudaki hesap, lisans, cihaz ve iptal kontrollerinden geçer.
- Ağ kesintisi kaydı silmez. Çıkış yapmak kaydı temizler. 30 gün boyunca hiç kullanılmayan uygulamada yeniden giriş gerekebilir.
- Yenileme tokenı sıradan API yetkisi olarak kullanılamaz. Süresi bitmiş veya bozuk kayıtlı access token başlangıç bağlantısına eklenmez; yenileme kaydı korunur.

- Üç odaklı dosya testi geçti: sınırlı silme, eski paket eşleştirme, ikinci açılışta yeni verinin korunması. Fiziksel yönlendirme sınırları da aynı testlerde doğrulandı.
- `cargo check --lib --features flutter,hwcodec,vram` ve portable packer kontrolü geçti.

- Docker bağlantı ve destek servisleri sağlıklı; yerel `/healthz` ve sabit CA ile doğrulanmış dış HTTPS `/healthz` yanıtı 200.
- Ayrı geçici PostgreSQL ile 15 sunucu regresyon testi geçti; canlı lisans/müşteri kayıtları testlerde kullanılmadı. Yeni API mevcut Docker destek projesinde yeniden oluşturuldu; veritabanı, proxy, rendezvous/relay ve anahtarlar korundu.
