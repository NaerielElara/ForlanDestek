# Forlan Destek 1.15.0 doğrulama

## Kontroller

- Değişiklik öncesi canlı veritabanı `deploy/forlan-support/backups/20261011-112911-before-1.15.dump` dosyasına yedeklendi (30.791 bayt).
- Son API kaynaklarıyla ayrı PostgreSQL ortamında **10/10 test geçti**. Müşterinin yalnız kendi aktif kayıtlarını okuması/yazması, geçmişinin boş dönmesi, kapalı kayıtların 404 vermesi ve mesaj sahibinin doğru dönmesi doğrulandı.
- Teknisyene bildir işleminin sahipliği koruması; yalnız seçilen alıcıya olay ve okunmamış sayacı üretmesi; mevcut teknisyenin mesaj göndermeye devam edebilmesi doğrulandı. Normal müşteri mesaj bildirimi korunuyor.
- Aynı testlerde lisans kodu yenileme/oturum iptali, hesap arşivleme, son yönetici koruması, lisanssız bağlantı süresi/bekleme ve lisanslı paralel bağlantılar geçti.
- Şema başlatma iki kez çalıştı. Alıcı yabancı anahtarı `ON DELETE CASCADE`; olay türü ve alıcı eşleşmesi CHECK ile doğrulandı. Bir teknisyen silinince kendisine ait özel olayın genel bildirime dönüşmesi engellenir.
- Geçici test veritabanı konteyneri ve ağı kaldırıldı. Canlı müşteri verileri test için değiştirilmedi.
- Yalnız `support-api` yeniden oluşturuldu. Yerel `/healthz` ve `/admin/` 200; CA/IP doğrulamalı internet HTTPS `/healthz` ve politika anahtarı 200; internet `/admin/` 404.
- Dört değişen Dart dosyası için analiz tamamlandı: hata/uyarı yok; mevcut ayar dosyasında beş bilgi seviyesi eski bildirim var. İlgisiz temizleme yapılmadı.
- Tam Windows Rust/Flutter release derlemesi başarılı. Son işlem geçmişi başlıkları için Flutter yeniden derlendi (157 saniye); Rust çekirdeği değiştirilmedi.

## Doğrulama sınırları

- Windows arayüz aracı uygulamayı açarken iki denemede `GetCursorPos failed: Erişim engellendi (0x80070005)` hatası verdi; canlı müşteri/teknisyen arayüzü ve animasyon gözlemi bu aşamada yapılamadı. Kaynak, analiz ve derleme kontrolü tamamlandı.
- İki gerçek Windows bilgisayarında seçilen teknisyenin toast/ses alması ve aktif destek görüşmesi uçtan uca denenmedi; alıcı ve sahiplik kuralları gerçek PostgreSQL testleriyle doğrulandı.
- Bildirim almak kaydı otomatik üstlendirmez. Sahibi işlem yapmaya devam eder; başka teknisyenin işi üstlenmesi için mevcut sahibin havuza bırakması gerekir.
- Bağlantı lisans kuralları yeni resmi Windows istemcisinde uygulanır; eski veya değiştirilmiş istemciler stock hbbs/hbbr tarafından lisansla kısıtlanmaz. Önceki güvenli API/imzalı izin koşulları korunur.
- GitHub yayını kullanıcı onayını bekler.
