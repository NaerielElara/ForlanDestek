# Forlan Destek 1.7.0

## Yenilikler ve düzeltmeler
- Güncelleme indirmesi artık Forlan Destek portable sürümünün gerçek GitHub dosya adını kullanıyor; indirme tarayıcıya düşmeden program içinde başlayabiliyor.
- Güncelleme düğmesine hover sırasında renk ve ölçü animasyonu eklendi.
- Ana ekrandaki Forlan Destek logosu ve yazı alanı büyütüldü.
- Adres defterindeki etiket paneli küçültüldü; etiketler kendi renklerinde rozet olarak bilgisayar kartlarında gösteriliyor.
- Adres defteri kartları daha kompakt hale getirildi; aynı ekranda daha fazla bilgisayar görünür.

## Test
- Windows x64 portable build.
- Güncelleme asset adı için regresyon testi.
- Flutter analyze çıktısında değişen kod için hata yok; depoda mevcut deprecated API bilgilendirmeleri bulunuyor.
